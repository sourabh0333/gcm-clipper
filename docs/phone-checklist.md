# Before the beta: two checks on your phone

Written 12 November 2026. About an hour in all. Open Kaatclip on your phone: **https://greenbornit.tailfc640f.ts.net**
(the laptop must be on). When something looks wrong or confusing, take a screenshot and send it to Claude.

---

## Part A: rate the clips (about 30 minutes)

We have never measured how good Kaatclip's picks are. Your swipes tell us.

Do these **3 test streams** (12 clips each). They are other streamers' streams used only for testing: **don't post
anything from them**.

| # | Stream (on the Streams tab) | Why this one |
|---|---|---|
| 1 | **RUSH GAMEPLAY WITH FACE CAM ON \| BGMI \| DIPEN...** (2 h 3 min) | Fights and a face cam |
| 2 | **NEW UPDATE 4.6.[1] धमाकेदार बकखोदी : BGMI LIV...** (3 h 8 min) | Lots of Hindi talk and funny moments |
| 3 | **AGGRESSIVE RUSH GAMEPLAY 😍\| FACECAM 😍\| VERTIC...** (30 min) | A vertical stream |

For each: open the stream → **Review 12 clips** → for every clip ask one question:

> **"If this were my stream, would I post this as a Short?"**

- **Yes → swipe right (Keep).**
- **No → swipe left (Reject)** and pick the reason that fits best:
  - **Bad cut**: the moment is good, but it starts too late, ends too early, or cuts the reaction.
  - **Not interesting**: nothing worth watching.
  - **Wrong moment**: it shows something else, not what it claims.
  - **Duplicate**: the same moment as another clip.

Be strict, like a real streamer would be. Also note (in a message to Claude) any **great moment you remember that
Kaatclip missed**, if you watched any part of these streams.

When all three are done, tell Claude **"rating done"**. Claude will count how many picks were good, by kind
(fights, funny, talk), and fix what's weakest before the beta.

## Part B: the full run-through (about 30 minutes)

Tick each step. Use **your own test recording** ("My test recording") or any clip you **won't post publicly**.

### Review and library
- [ ] Streams → open a stream → the clips list, progress, Review button make sense
- [ ] Library → search a word that was said ("bhai", "clutch") → the right clips come up
- [ ] Library filters (Kept, Not reviewed, a stream) work

### Studio and editor
- [ ] Open a kept clip → the preview plays smoothly (no long loading)
- [ ] **Open editor** → **Cut**: drag the start and end, split into two parts, delete a part
- [ ] **Layout**: try each template (native, blur, band, split); move the face-cam box if needed
- [ ] **Zoom**: turn zooms on kills on and off; **Sound on zooms**
- [ ] **Text**: change the hook title, pick another suggestion, change its colour
- [ ] **Captions**: turn on, fix a wrong word, try Devanagari, bigger size
- [ ] Set the **cover** frame ("Cover here")
- [ ] Save → back in Studio → **Export** → the video appears under Exports and plays
- [ ] **Make another version** → Export it → it has a different title and length
- [ ] **Copy Reels caption** → paste it in Notes: it looks right for Instagram
- [ ] **Download** saves the video to the phone; **Share** opens the share sheet

### Brand kit and thumbnails
- [ ] Settings → Brand kit: add your name, a logo, the hook colour; export a clip again → it shows
- [ ] A stream page → **Thumbnails and titles** → Make them → 3 thumbnails and 3 titles appear
- [ ] Library → **Weekly compilation** → make one → it plays with chapters

### Posting (don't approve anything you don't want public; you can Delete drafts)
- [ ] Post to YouTube → the draft shows title, description with "Full stream", channel, time
- [ ] **Posts → Week**: the calendar, the Shorts-share gauge, **Move** a draft to another day
- [ ] **Posts → Month** and **List** views
- [ ] Delete the test drafts afterwards

### The rest
- [ ] Streams page → **Your channel** card shows your numbers (or "not in yet")
- [ ] **Live** tab → I'm live → Mark moment → Stream ended
- [ ] Settings → Telegram connected (a message arrives when clips are ready)
- [ ] Everything reads fine on the phone: no cut-off text, no buttons hidden behind the bottom bar

When done, send Claude: **what annoyed you, what confused you, what you'd change**, with screenshots.
