# AI-GCM

AI that turns long BGMI gameplay recordings and livestreams into ranked, captioned short clips for Indian gaming creators.

| Folder | What's in it |
|---|---|
| [reports](reports/) | Market validation report: competitors, Indian BGMI creator market, feasibility, risks, verdict |
| [plans](plans/) | 6-week validation plan: decision gates, interview script, blind clip test, paid pilot offer |
| [research_notes](research_notes/) | Source notes behind the report, with links |
| [ai-gcm](ai-gcm/) | Working prototype (Python): download, HUD and audio analysis, ranking, captions, 9:16 clips, review page |

See [ai-gcm/README.md](ai-gcm/README.md) to set up and run the prototype.
